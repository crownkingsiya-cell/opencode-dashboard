# OpenCode Dashboard

A modern dashboard app scaffolded for an AI coding workflow built around the `anomalyco/opencode` repository context.

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Features

- repository health overview
- live activity feed
- task queue panel
- responsive dashboard UI
- ready for API integration and GitHub auth
